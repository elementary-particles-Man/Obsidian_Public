# Policy Document

## ステーブルコインを利用した決済インフラの整備に関する政策提言  
（THP-CLEAR実装構想に基づく提言）

### 1. 提言の趣旨と背景

近年、世界経済は複合的な要因により著しい不安定化を見せており、いわゆる**「複合災厄（ワルプルギス）」**がすでに進行している。  
金価格の急騰、米国内政の混乱、州債・市債市場の脆弱化等が顕著で、国際決済機構の信頼基盤が揺らいでいる。

特に米国ではイリノイ州などの州債信用低下が拡大しており、カリフォルニア等大規模経済圏に波及すれば、**金融取引の麻痺から実体経済の停止**に直結する。  
最悪の場合、ニューヨーク／シカゴを中心とする**米国決済網の停止**が国際エネルギー・食料・物流供給に連鎖する恐れがある。

日本は依然としてドル建て決済への依存が高く、ドル停滞は即座に**電力・物流・食料**へ影響する。  
よって「**円による即時決済が可能な代替ネットワーク**」の構築が急務である。

---

### 2. 提言の骨子

本提言は、既に設計・実装が完了している**分散監査型決済基盤 THP-CLEAR**を基に、  
**JPYC等ステーブルコインを用いた次世代決済インフラを政府主導で整備**することを目的とする。

#### （1）目的

- 既存通貨に基づくステーブルコイン（フィアット完全準拠）／E-20互換による**即時決済網の確保**
- 国家主導の**取引透明性・監査証跡（Witness）**の確立
- 有事・停電時を含む**継続的な決済可用性**の維持

#### （2）概要

- JPYC（円建てステーブルコイン）を基幹とし、**SMBC／Google／Apple**と連携。  
- バーチャルデビットカードによる**リアルタイム決済**を実装。  
- THP-CLEARは決済情報の**真実相当性（When／Who／Whom／Coin／Value）**を監査し、事業者主張を第三者的に裏付け。  
- AI（Ricoh等）による金融判断を監査対象化し、**AI監査の真正性を保証する唯一の機構**とする。

---

### 3. 技術構成の概要

#### （1）ハードウェア構成
- 8コア-16スレッド（TDP 35W以下）の省電力ミニPC。
- OS：Linux、SSD：NVMe 512GB～1TB。  
- 全国自治体ネットワークに**1,000ノード**を分散配置。  
- 「**電源を入れるだけで稼働**」、異常検知時は**リモート停止→交換**。  
- **原則UPS常設は不要（運用判断で例外可）**。

#### （2）ソフトウェア構成
- 実装済みソフトウェア：**THP-CLEAR（Go言語）**。  
- 暗号層：**ISE（恭順暗号）**、復号不要。  
- **KMSはDB内KeyHub（KMS-in-DB）**構成。署名・鍵配布を同層で統合管理。  
  ※独立KMS Ring（3台以上／quorum=2）は代替構成。

---

### 4. 運用・監査構造
- 各ノードで即時ハッシュ化・署名、東西DC二拠点クラスタで整合。  
- Prometheus／Grafana によるリアルタイム監視。  
- ノード障害は自動検知・交換同期で即時復旧。  
- 監査証跡を伴う**即時性と改竄耐性**を確保。

# Technical Specifications（E-20準拠抜粋）

- **署名**：Ed25519、**通信**：TLS/mTLS。  
- **KMS：DB内KeyHub（KMS-in-DB）**（代替：独立KMS Ring）。  
- **監査ログ**：`session_id / kms_endpoint / latency / failover_count`。  
- **データ層**：Witness（JSONL＋Merkle）→SQLite。  
- **監視**：Prometheus／Grafana（`kms_*` 指標）。  
- **構成**：MQ8GB／WN4GB／DB4GB＋SSD4TB×2。  
- **UPS原則不要／運用判断で例外可**。
