# 0. 背景と構造（論理骨格）

- **A（支払意思）**：政府運営・OMB通達の語彙が市場の“米国の意思”へ直接投影される。
    
- **B（資金機能）**：短資市場の摩擦（GC–SOFR、ON RRP、SRF、FXベーシス）と、**FICC「日中IM/VM」**のプロシクリ効果が入札の弾性を削る。
    
- **C（国際信頼）**：NATO/核言辞の逐語強度が「予備的リスク・プレミアム」を押し上げる。
    
- **D（供給・制裁）**：OFAC/保険（P&I）/海運・エネルギーの遮断は、短期的にドル需要とリスク資産の割引率に波及。
    

入札結果＝ f（A×B×C×D, 前日WI乖離, ディーラー在庫, ミスディレで“静かに通過”した規制技術要因）。  
この関数の**最大の非線形性はB（流動性）**にある。**サイバー×日中IM/VM×ベーシス悪化**が同時化すると、通常の需要曲線が崩れ、テールが跳ねやすい。

# 1. シナリオ体系（三分岐）

## S1：**成立（浅いテール）** — 構造的安堵だが一時的

**条件論理**

- NATO/WHの語彙が“抑制的”〜“firm止まり”。
    
- 短資の摩擦が**枠内**（GC–SOFR ±10bp、ON RRPの流入は+100〜200B程度、SRF未発動）。
    
- WI乖離が −0〜−3bp 程度で安定（前日に弱含みでも増幅しない）。
    

**結果の像**

- **テール**：+1〜+3bp。
    
- **Bid-to-Cover**：≳2.30x、**Indirect**：≳60%。
    
- **金利曲線**：5–10yやや弱含み→引けにかけ買い戻し。
    
- **為替**：円高進行は一服、DXYは横ばい〜小反発。
    
- **信用**：UST/GSIB CDSは横ばい〜小縮小、VIX < 25。
    

**波及**

- 30日単体では“延命”に成功。ただしA・Cの火種は残存、**Bの構造摩擦**（日中IM/VMルール・サイバー警戒）の限界は温存。**10月前半に再テスト**の可能性。
    

---

## S2：**成立（深いテール）** — 「心理→価格」の本格反映

**条件論理**

- NATO/WHの語彙が「decisive/kinetic」の層、ただし“shoot down／nuclear即時”までは踏み込まない。
    
- 短資の摩擦が**閾値近傍**（GC–SOFR +10〜+20bp、ON RRP +≥200B、ベーシス USD/JPY −50bp付近）。
    
- **WI 乖離が −4〜−7bp**で寄りから拡大、FICC「日中IM/VM」発効・増額や“境界機器のサイバー継続注意”が**ディーラー余力を吸う**。
    

**結果の像**

- **テール**：+4〜+7bp。
    
- **Bid-to-Cover**：2.05〜2.25x、**Indirect**：55〜60%。
    
- **金利曲線**：5–10yでテール反映の上振れ→のちに押し目買い、形状は**ベア・スティープ/ベア・フラット混在**。
    
- **為替**：DXY反落、USD/JPYは**円高拡大**（−1.5〜−3%相当の圧力が出やすい）。
    
- **信用**：UST 5y CDS +10〜+25bp、G-SIB CDS +10〜+30bp、VIX ≥ 30 接近。
    

**波及**

- **翌営業日の再入札/再調達に影**。財務省の**Buyback示唆／CMB（現金管理短期債）**による微修正の観測が浮上。
    
- **B（流動性）**の非線形域に片足。**“不成立の尾”**が濃くなる。
    

---

## S3：**不成立／技術的延期（Red系）** — 形式は技術、実体は信用

**条件論理**

- NATO/WH 逐語が**“shoot down / engage”級**、または“nuclear/immediate”級。
    
- 短資の摩擦が**閾値突破**（GC–SOFR +≥20bp、ON RRP +≥250B、**SRF発動**、USD/JPYベーシス ≤ −80bp）。
    
- **WI 乖離 ≥ −8bp**、ディーラーの**日中IM/VM**と在庫制限、**サイバー運用の追加ディスラプション**で主力参加者の実弾が枯れる。
    

**結果の像**

- **不成立／延期**、または**極端な深テール（+8〜+12bp）とカバー不全**。
    
- **金利曲線**：初動は急騰、その後は“品質逃避”がUST最長限の一部に逆流する挙動もあり得る（トリプルトラック）。
    
- **為替**：混相。USD現金需要↑による瞬間的ドル高と、基軸信用毀損→ドル売りの綱引き。**短期では円高優位**になりやすい。
    
- **信用**：UST/米国家CDSの急拡大、G-SIBのCDSも連動、VIX 30台後半〜。
    

**政策反応（論理的優先順）**

1. 財務省：**Buyback/スケジュール調整／CMB発行**。
    
2. FRB：**SRF積極活用の啓示／国際スワップ・ライン**の点検（必要なら増枠）。
    
3. 同盟中銀：**協調流動性**の声明。
    
4. 規制：**FICC「日中IM/VM」運用のテクニカル緩和**（一時措置の検討余地）。
    

**波及**

- **“ワルプルギス”本体に接続**。A/B/C/Dの四柱同時悪化が顕在化し、**“延命の選択肢”が政策コミュニケーションの巧拙に依存**する局面へ。

# 2. 事前に定める「検証フレーム」（当夜の照合手順）

1. **順序検証**：  
    〔逐語（A/C）→ 短資（B）→ WI乖離 → 入札結果〕の順で因果が並んだか。
    
2. **到達検証**：  
    閾値（GC–SOFR、ON RRP、ベーシス、WI差）に到達した**数**と**同時性**。
    
3. **方向検証**：  
    想定レンジの**方向**が適合したか（例：円高、CDS拡大、VIX上昇）。
    
4. **反応遅延**：  
    不成立系では、初動の“金利急騰→避難の逆流”が**時間差**で起き得る。**T+15分／T+60分**で二点観測。
    
5. **政策リアクション窓**：  
    Buyback/CMB/SRF/スワップの**通信順序**を時刻列で保存。**順序の破綻**が二次パニックの有力因子。

# 3. “論理の地図”（シンプル因果）

- **サイバー継続→境界機器負担↑ →** 波状的**ボラ↑ → IM/VM↑ → ディーラー余力↓ → WI乖離拡大 → テール↑**
    
- **NATO語彙強度↑ →** 核・撃墜ボラ・プレミアム↑ → **国債需要の安全弾力↓ →** 入札脆弱化
    
- **保険・制裁→海運摩擦↑ →** エネルギー価格↑ → **短期インフレ懸念↑** → 実質利回り上振れ → **価格受容度↓**
    

この**三系統が同時に“Amber”**に乗るだけでS2化しやすく、**どれかが“Red”**へ進むとS3方向の引力が強まる。

# 4. 事後レビューで残す“検証可能な約束”（テスト可能命題）

1. **S2成立のとき**：  
    　**WI乖離（−4〜−7bp）とON RRP（+≥200B）の同時成立**が見られる。
    
2. **S3（不成立/延期）のとき**：  
    　**SRF発動**または**USD/JPYベーシス ≤ −80bp**が**入札前後1時間**に同定できる。
    
3. **S1成立のとき**：  
    　**VIX <25**かつ**G-SIB CDSの拡大が10bp未満**に留まる。
    
4. **政策反応の効果**：  
    　Buyback/CMB/SRF/スワップの“順序が早いほど”VIXの**二段加速**は抑制される。
    

これらは**論理的に反証可能**であり、実測により黒白が付く。
