# Walpurgis 第IV-D部：ユーロ圏の断裂

## エグゼクティブサマリー：ドゥーム・ループの帰還

ユーロ圏は2011〜2012年のソブリン債危機以降、相応の防壁を築いてきた。しかし本レポートは、ワルプルギス級のシステム全体ショックの前では、これらが依然として不完全で、破綻し得ることを示す。

ユーロ圏の脆弱性の中核は依然として「ドゥーム・ループ」――銀行と自国政府の自己強化的なフィードバックである。分析は3つの主要知見を強調する：

1. ドゥーム・ループは構造的である。銀行が自国ソブリン債を過大に保有する「ホームバイアス」は温存されている。これは制度枠組みと規制の意図せざる帰結であり、政府債が破綻しないことを前提にしたルールが、銀行を自国にハードワイヤする。
2. 解決（レスキュー）のトリレンマ。監督当局は「厳格なベイルイン規則の適用」「金融安定の維持」「国家補助（State aid）規律の遵守」という3つを同時に満たせない。歴史的に、金融安定と政治判断がルールの厳格適用を凌駕しがちである。
3. 社会の分断は金融リスクを増幅する。緊縮への反発が政府の行動能力を弱め、そのリスクは即座に国債の資金調達コスト（リスクプレミアム上昇）に価格転嫁される。

耐性は以前より高まったが、ユーロ圏はこの規模のシステムショックに未だ晒されておらず、防壁は裁量的・政治的で、最終的には限定的である。

### なぜ重要か

断片化は抽象的な市場談義ではない。住宅ローン金利、中小企業向け与信、預金の安全性――加盟国ごとに直撃する。ユーロ圏の金融配管の安定は日常生活に直結する。

## 第1章：銀行—国家ネクサスの解剖

### 1.1 ドゥーム・ループ再考

銀行とソブリンの自己強化ループは、ユーロ圏の金融安定に対する主要な脅威のままである。これは4つの相互接続したチャネルで動作する：

1. 銀行バランスシート・チャネル：銀行は自国ソブリン債を大量に保有する。政府の信用力が低下すると債券価格が下落し、自己資本を直接侵食する。
2. 担保チャネル：ソブリン債は銀行間・中銀ファンディングにおける最重要担保である。格下げは借入余力を縮小させ、流動性逼迫リスクを高める。
3. 政府保証チャネル：銀行システムが動揺すると、政府の暗黙のバックストップが期待される。財政が脆弱な政府は信認ある保証を提供できず、取り付け（バンクラン）のリスクが高まる。
4. マクロ経済チャネル：ソブリン危機は緊縮を強要する。需要低迷はデフォルトを増やし、銀行の与信品質を悪化させる。

### 1.2 脆弱性の可視化：ソブリン・エクスポージャー

欧州銀行監督機構（EBA）のデータは「ホームバイアス」の持続を裏付ける。以下の通り、過去にソブリン・ストレスを経験した国（伊・西・希）では、国内ソブリン・エクスポージャーがCET1（中核自己資本）の約2倍に達している。

## 第2章：システミックな脅威としての断片化

金融の断片化とは、単一金融政策の加盟国間への伝播が不均一になること――中央の政策が均等に波及しない失敗である。

### 2.1 リアルタイム指標：スプレッドとTARGET2

- ソブリン・スプレッド：各国の国債利回りと独連邦債（Bund）との利回り格差は、ソブリン・リスク認識を直接反映する。スプレッド拡大は断片化リスクの上昇を示す。²
- TARGET2不均衡：ユーロ圏の内国間決済（TARGET2）は通貨同盟内の資本移動を反映する。恒常的な不均衡は資本移動を示唆する。量的緩和（QE）が解釈を複雑化するが、スプレッド拡大と同時にTARGET2残高が急拡大する局面は、資本逃避の早期警戒シグナルとして信頼度が高い。³

### 2.2 実体経済への伝播

断片化は市場現象に留まらない。与信収縮と預金流出を通じて実体経済を直撃する。ソブリン・リスクの上昇は国内銀行の貸出態度を厳格化させる。また、預金者がより安全と見做す地域へ資金を移すことで、デジタル/越境での「サイレント・バンクラン」を誘発し得る。

> モニタリング指針：スプレッド、銀行CDS、TARGET2の3計器を見よ。三者が同時に拡大する時、断片化リスクは顕在化している。

² 2011〜2012年危機では、伊10年国債（BTP）と独Bundのスプレッドは500bp超に拡大した。  
³ QEの機械的効果によるTARGET2残高の拡大と、ストレス由来の急伸（資本逃避シグナル）は区別せよ。

## 第3章：ユーロ圏の制度的ガントレット

ユーロ圏はシステミック・リスクに対処する複合的枠組みを構築したが、根源的な緊張を内包する。

### 3.1 財政バックストップ：安定成長協定（SGP）

SGPは財政赤字と公的債務に上限を課すが、執行は高度に政治的である。規律順守のための財政再建は、社会不安を招き、結果としてソブリン・リスクを高めるという政策上の板挟みを生む。

### 3.2 ループ切断：銀行回復・破綻処理指令（BRRD）

BRRDは「ベイルイン」の原則を導入し、納税者ではなく株主・債権者に損失負担を求める。⁴ しかし厳格適用は「解決のトリレンマ」を生む――(i) ベイルインの執行、(ii) 金融安定の維持、(iii) 国家補助規律の順守を同時に満たせない。システミック危機では金融安定が優先されがちだ。

### 3.3 最後の砦としてのECB：TPI（伝達保護手段）

欧州中央銀行（ECB）の最終バックストップはTPIであり、「不当で無秩序な市場力学」に対して加盟国の国債を購入し得る。TPIは「裁量的・適格性審査ベースのバックストップ」であり、ルールベースの安定化装置ではない。介入はメトリクスだけでなく政治にも左右される。

⁴ 公的支援の前に、銀行の自己資本等を含む「総負債等」の**8％**以上のベイルインが必要（BRRD）。

## 第4章：社会的断層

金融システムは社会・政治現実の中に埋め込まれている。

### 4.1 安定の代償：緊縮・騒乱・リスクプレミアム

連鎖は単純だ――「財政ストレス → 緊縮 → 社会不安 → 高いリスクプレミアム」。再建要求は抗議・暴動・ストライキを誘発し、これがソブリンの借入コスト上昇へ直結する。

### 4.2 政治の断片化

騒乱は政治を分断し、ポピュリズムや欧州懐疑の勢力を伸長させる。政策不確実性は上昇し、制度的ファイアウォールは弱まる――そして再びドゥーム・ループへフィードバックする。

## 第5章：統合ストレス・シナリオ

ワルプルギス級ショック下での論理的な事象連鎖：

1. 初期ショック：グローバルなリスク回避でクオリティへの逃避が発生。周縁国（ペリフェリー）のスプレッドが急拡大し、銀行B/Sに時価評価損を与える。
2. 制度の不作動：政治対立がTPI発動を遅らせる。大手銀行の解決が必要になるが、当局はトリレンマに縛られ意思決定が麻痺する。
3. 社会的増幅：市場の信認回復のため、政府は急進的な緊縮パッケージを公表し、これが大規模抗議と政治危機を誘発。
4. 終端ループ：政策空白からソルベンシー危機へ。信認低下が深まり、家計・企業の資金移動で預金流出が加速。
5. 最終フィードバック：政治危機で同国は実質的にTPI適格性を失う。市場はECBが介入しないと解釈。ソブリン・スプレッドはスパイラルし、銀行システムは健全性危機に転落。ドゥーム・ループが完成し、ユーロ圏は制御不能なシステミック事象へと押しやられる。
