# Walpurgis 第IV-C部：社会・倫理ショック

## エグゼクティブサマリー：社会契約の崩壊

本稿は、ドル債務不履行危機（DDC）によって連鎖的に引き起こされる社会・倫理ショックの体系を分析する。金融・政治・資源ショックに関する先行レポートで提示した定量枠組みを前提とする。

DDCは単なる金融危機ではない。先進諸国における国家能力の急速かつ構造的な崩落を意味する。その一次的伝播経路は、「民間の富」と「国家の歳入」が同時に破壊されることにあり、これが緊縮・大量失業・社会不安の自己強化サイクルを駆動する。既存の制度設計は、この種の複合ショックに対して致命的に準備不足である。

【主要想定（中期シナリオ）】 ベースラインの「L2：壊滅的シナリオ」では、以下を見込む。世界の金融資産損失は「12兆～21.6兆ドル」に達し、実体経済に深刻な打撃を与える。世界のU6相当失業率はベースから「10～15ポイント」悪化し、大恐慌に匹敵する規模となる。これにより、発災後6カ月で「5,000万～8,000万人」の国際・国内移動（移民・難民）が発生。先進国では凶悪・財産犯罪が前年比「30～50％」増加し、治安は著しく悪化する。

【地域別の主要脆弱性】 影響は地域により大きく異なる。

- 北米・欧州：金融システムの震源として、労働市場の崩壊と社会的結束の喪失に最も深刻に直面。EUは、財政規律（安定成長協定）と社会不安対応のジレンマに晒される。
- 中東・サハラ以南アフリカ：食料・エネルギー輸入能力の喪失により、広範な飢饉と国家崩壊が発生し、欧州に前例のない移動圧力を与える。
- 東アジア：輸出需要の蒸発に伴う製造業の連鎖倒産と、重要サプライチェーンの寸断が主要リスク。

【戦略的含意】 本分析は3つの重大課題を示す。第一に、民主主義国を含む多くの国で、国内秩序維持のために非常権限が発動され、権威主義的統治への移行リスクが極めて高い。第二に、食料・医薬などの必需の配給は理論上可能でも、国家能力の低下と闇市場の拡大により運用は困難。第三に、偽情報や扇動に満ちた情報環境が社会の断片化を加速し、暴力への心理的閾値を大幅に下げる。DDC後の世界では、金融秩序のみならず、リベラル・デモクラシーと社会契約そのものが根本から問われる。

## II. メカニズム・マップ：社会崩壊の力学

DDCの金融ショックから社会構造の破断に至る因果連鎖は、複数の自己強化的フィードバックで特徴づけられる。本節は時系列に伝播機構を解剖し、以降の分析の論理基盤を与える。

### 2.1. 初期伝播（T+0～30日）：金融崩壊から実体経済の動揺へ

DDCは米国債入札の技術的失敗により点火する。これは世界の「無リスク資産」の消失を意味し、瞬時にリスクの全面的な再価格付けを引き起こす。L2シナリオでは、金融資産損失は「12兆～21.6兆ドル」と試算される。この規模の富の破壊は、ただちに実体経済へ波及する。

一次的な伝播経路は「資産効果フィードバック」である。米国の金融資産／GDP比が約6倍であることを踏まえると、巨額の資産蒸発は家計と企業の信認を打ち砕き、消費・投資を急停止させる。

この初期ショックは、2008年危機後に構築された規制枠組み自体によって増幅される。補完的レバレッジ比率（SLR）や清算機関（CCP）のマージン・コールは強い順循環性を持ち、ボラティリティ急騰時に流動性を吸い上げる。これにより壊滅的な「流動性デス・スパイラル」が自己強化され、信用市場が凍り、実体経済の血流が断たれる。

### 2.2. 悪循環（T+1～6カ月）：失業・緊縮・騒乱

信用凍結と需要蒸発は大規模レイオフの波を引き起こす。歴史的に、金融危機は建設や製造など信用依存度の高い部門を最初に直撃し、その後サービスや公的部門へ波及する。DDCの規模を踏まえると、この過程は過去のどの危機よりも速く、広く進行する見込みだ。

経済活動の崩壊は租税基盤を破壊する。DDC環境では国際市場からの新規借入が不可能となり、政府は歳出を歳入に合わせるほかない。社会的支援需要がピークとなる正にその時に、「スーパー緊縮」を強いられる。

この状況は社会不安の強力な加速器として機能する。Ponticelli & Voth（2020）は、政府支出削減幅と騒乱（暴動・デモ・ゼネスト）の頻度との間に強い正の相関があることを示した。DDC下では、多くの国でGDP比5％超の削減が不可避であり、社会不安の頻度は非線形に増大し、基準値の2倍超に跳ね上がる可能性が高い。

社会不安は実体経済をさらに混乱させ、治安コストを押し上げる。政府は一層の歳出削減を余儀なくされ、再び不安を煽る――破壊的なループである。これは、金融ショックが社会的結束の崩壊へ直結する中核メカニズムだ。

【因果連鎖図】 DDC（金融ショック） → 資産価値崩落 → 信用収縮・需要蒸発 → 大量失業 → 税収崩壊 → 社会不安増大 → 公共サービス削減 → 強制緊縮 → さらなる停滞と治安コスト → 財政悪化 →（ループ）

### 2.3. システム不全（T+6～24カ月）：国家機能麻痺と生存ダイナミクス

上記の悪循環が臨界点を越えると、国家は基本機能（治安維持・インフラ管理・社会保障）を果たせなくなる。この段階で、統治の正統性を維持するために、政府はより強権的な手段に訴える：非常権限の発動、必需の配給制度の導入である。

同時に、国家が提供する安全と機会が消えるにつれ、人々は自己の手段で生存を求め始める。これが越境的な大規模移動・難民流を引き起こす。国内では闇市場・地下経済が国家統制を超えて拡大し、税基盤と正統性をさらに侵食する。この段階で、危機は完全に経済から政治・社会へと転化し、国家の存立そのものを問い直す。
