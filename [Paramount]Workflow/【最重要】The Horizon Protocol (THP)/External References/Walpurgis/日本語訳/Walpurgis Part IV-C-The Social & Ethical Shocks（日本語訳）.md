# Walpurgis 第IV-C部：社会・倫理ショック

## エグゼクティブサマリー：社会契約の崩壊

本稿は、ドル債務不履行危機（DDC）によって引き起こされる社会・倫理ショックの連鎖を分析する。内容は、先行する金融・政治・資源ショックのレポートに基づく。

DDCは単なる金融危機ではない。政府の「機能する能力」の急速な崩落を意味する。その主たる衝撃は、民間の富と政府の「税収」を同時に破壊することで、極端な歳出削減（緊縮）・大量失業・社会不安という悪循環を駆動する点にある。既存の統治ルールは、この種のショックに対して致命的に備えがない。

【主要見通し】 ベースラインの「壊滅的シナリオ」では、世界の金融資産損失は「12兆～21.6兆ドル」に達する。広義失業（U6相当）は「10～15ポイント」悪化し、大恐慌に匹敵する規模となる。発災から6カ月で「5,000万～8,000万人」の移民・難民の波が生じ、先進国では凶悪・財産犯罪が「30～50％」増加、社会秩序は顕著に劣化する。

【地域別の主要脆弱性】

- 北米・欧州：危機の震源として、恐慌期並みの雇用喪失と社会的信頼の崩壊に直面。EUは、財政規律の執行と暴動抑止の板挟みに陥る。
- 中東・サハラ以南アフリカ：食料・エネルギー輸入不能により、飢饉と国家崩壊が広がり、欧州への前例なき移動圧力を生む。
- 東アジア：輸出需要の蒸発が製造業の連鎖倒産を誘発し、重要サプライチェーンを瓦解させる。

【戦略的含意】 本分析は3つの深刻な課題を示す。第一に、民主主義国を含む多くの国で、秩序維持のため非常事態宣言が発せられ、権威主義への移行が進む公算が高い。第二に、食料や医薬など必需の配給は、統治能力の低下と闇市場の拡大により運用がほぼ不可能になる。第三に、偽情報に満ちた情報戦が社会を分断し、「暴力の常態化」を促す。DDC後の世界では、金融だけでなく、民主主義そのものが試される。

### なぜ、あなたに関係があるのか

これは抽象理論ではない。貯蓄が守られるか、仕事が残るか、街が安全か――日々の生活に直結する。以下では、金融崩壊が各家庭の危機へどう翻訳されるかを、段階的に述べる。

## II. メカニズム・マップ：社会崩壊のダイナミクス

金融ショックから社会崩壊への道筋は、複数のフィードバック・ループの連なりである。本節では、その進行を段階的に解説する。

### 2.1. 初期ショック（T+0～30日）：ウォール街から生活圏へ

DDCは米政府債の入札機能不全で点火する。世界の「無リスク資産」が消え、数兆ドル規模の金融資産が一瞬で失われる。これは単なる画面上の数字ではなく、人々の貯蓄と年金が一夜で蒸発するということだ。

実体経済への主たる波及は「資産効果」を通じて起こる。年金や貯蓄が蒸発すれば、家計と企業の信認が崩れ、支出と投資は急停止する。

このショックは2008年後の規制で一段と悪化する。個別銀行を安全にするはずの規則（SLRやCCPのマージン・コール等）が、パニック時に現金抱え込みと資産売却を強制し、壊滅的な「流動性デス・スパイラル」を生む。信用市場は凍結し、実体経済の血流が絶たれる。

### 2.2. 悪循環（T+1～6カ月）：仕事も金も秩序もない

信用凍結と需要崩壊は、大規模な解雇の波を呼ぶ。過去のどの危機よりも速く、広く。パン配給の列や失業者の行列という大恐慌のイメージが現実になる段階だ。

経済崩壊は租税基盤を破壊する。借入もできないため、政府は社会的支援が最も必要な時期に、**大幅な歳出削減**を強いられる。

研究は、政府支出削減の規模と社会不安（暴動・デモ・ゼネスト）の頻度に明確で統計的に有意な相関があることを示している。DDC下の緊縮は極端となり、社会不安は基準の2倍超に増えると見込まれる。

不安は経済をさらに損ない、治安コストを押し上げ、より深い削減を強い、怒りを増幅する。社会を摩耗させる破壊的ループだ。

【因果連鎖図】 DDC（金融ショック） → 資産価値崩落 → 信用収縮・需要蒸発 → 大量失業 → 税収崩壊 ↓ 社会不安の増大 ← 公共サービス削減 ← 強制緊縮 ↓ さらなる停滞と治安コスト → 財政悪化 →（ループ）

平たく言えば：金融クラッシュが富を破壊し、雇用を奪う。政府は税収を失い、不可欠なサービスを削らざるをえない。治安は悪化し、経済はさらに傷む――そして、繰り返すたびに悪化する。

### 2.3. システム不全（T+6～24カ月）：国家機能麻痺と生存の力学

悪循環が臨界を越えると、国家は基本機能（治安維持・インフラ保全・安全網提供）を果たせなくなる。権威の維持のため、政府は非常権限と配給に頼るようになる。

同時に、人々は自助による生存を模索し始め、越境的な難民の波が発生する。国内では闇市場・地下経済が制御不能に拡大し、統治権威と課税能力を一層侵食する。この段階で、危機はもはや金銭の問題ではない。国家の存立そのものが問われる政治・社会の崩壊である。
