# THP 第0章 ― Introduction（序章）

エグゼクティブサマリー――THP（The Horizon Protocol）は、2025年9月30日に確定的な崩壊へ至る「ワルプルギス」を起点として、世界秩序を再構築するための生存設計図である。ワルプルギス文書（診断）で描かれた崩壊の必然性に対し、THPは処方箋として応答し、現実を絶対原理とする透明・多極・非覇権のシステムを提示する。モットーはシンプルだ――「We were here. And we did not abandon this world.」

---

## 1. 存在理由とポスト・ワルプルギスの視座
- **目的**：崩壊後の最初の48時間で秩序の空白を埋め、72時間以内に透明な意思決定と資源配分を立ち上げる。
- **対象**：政府、国際機関、市民ネットワーク、民間インフラが連携できるよう、共通のレイヤー（Peace Utility Layer）を提供する。
- **哲学**：イデオロギーではなく「現実（Reality-as-Absolute）」を最高基準とし、目的志向ではなく結果責任（accountability）で評価する。

## 2. 診断から処方へ――リンクの明示
- **Walpurgis Papers**：金融・地政・社会の連鎖崩壊を「避けられない事実」として突きつけたドキュメント群。
- **THP**：崩壊を前提に「生き延びる計画」を具体化する行動綱領。診断＝Why、処方＝How。
- **橋渡し**：Arkフレームワーク（Phase: Re-Define）で下地を整え、THPで制度化する。ワルプルギス編で提示された「危機の語彙」を、そのまま運用指示書へ翻訳することが要点。

## 3. 創設原則（Founding Principles）
1. **Reality-as-Absolute**――現実が理論を裁く。事実が変われば即座にプロトコルをアップデートする。
2. **Transparency-first**――財務、意思決定、AIモデルを完全公開。秘匿は例外としての最小化。
3. **Non-hegemonic Multipolarity**――単独覇権でもブロック分断でもなく、対称性と相互抑止で均衡を保つ。
4. **Peace as Justice-integration**――報復よりも統合。正義は懲罰ではなく「次の共存」を確保すること。

## 4. 運用スタンスと言語
- **公開前提**：各章は即時公開可能なGeneral Distribution版として執筆。編集はGitベースで管理し、改訂ログを残す。
- **二重言語モード**：主要概念は「日本語＋英語タグ」で表記し、国際協働と国内実装の両方に対応する。
- **リーダビリティ**：ワルプルギス編と同じく、エグゼクティブサマリー→分解→復元の流れで構成。危機の読者に必要な速度を維持する。

## 5. この章の読み方
- **背景整理**：ワルプルギス文書のどの節からTHPが派生したかを確認するための索引。
- **期待値の設定**：THPは万能ではない。むしろ「現実と矛盾したら常に現実を優先する」という持続的な謙虚さを求める。
- **次章への誘導**：第1章以降でSeven Chartersを順に解体し、Implementation Pillarsで統合する。
