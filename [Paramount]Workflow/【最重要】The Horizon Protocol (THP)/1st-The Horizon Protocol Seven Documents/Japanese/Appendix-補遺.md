# Appendix - 補遺：LSCの哲学

## 研究版 (Detailed Version)

### 序文：LSC - 現実改善のための思考OS
LSC（天秤資本主義 / Libra/Scales Capitalism）は、The Horizon Protocol (THP) の全ての設計思想の根底に流れる「思考のオペレーティングシステム」である。その名は「資本主義」と付いているが、これは最終目標が「金融市場と実体経済の共存・均衡」にあるためで、本質はイデオロギーや教義ではない。LSCは、複雑で矛盾に満ちた現実の問題を、現実的な手段で改善し続けるための「汎用思考支援システム」である。

他の「〇〇主義」が固定的な「あるべき姿」の達成を目標とするのに対し、LSCにはそれがない。唯一の行動原理は「無駄で非生産的な対立や浪費（＝めんどくさいこと）をやめる」ことである。故にLSCは不変ではなく、現実の変化に合わせて自己の形を常に変え続ける「可変随時」の哲学である。

その実践のため、LSCは以下の七つの公理（Axiom）から成るコア構想を持つ。この七つの公理を理解し、現実の問題に適応させること（モジュール構築）が、LSCの全てである。

### LSCを構成する七つの公理

1.  **公理１：異常こそ尊い**
    常態（Normal）は、安定しているが故に価値の変動が少ない。対して、平和（戦乱が常態）、生命（死が常態）、覚醒（睡眠が常態）といった「異常（Abnormal）」は、極めて稀で一時的な奇跡であり、だからこそ圧倒的に価値が高い。我々が守るべきものは、この尊い「異常」である。

2.  **公理２：色即是空、空即是色 (Nothing is Everything)**
    万物は流転し、永遠不変の価値は存在しない。ある状況での「無」は、別の状況では「無限」の可能性を秘める。絶望の淵にこそ希望が生まれ、ゼロベースからこそ革新が生まれるように、0と∞は等価である。この認識は、我々を固定観念から解放する。

3.  **公理３：価値の相対性（生命を除く）**
    あらゆる価値や意味は、観測者とその状況によって変化する。砂漠の遭難者にとって一杯の水が持つ価値は、富豪の日常では無価値に近い。唯一の例外は「生命」である。いかなる状況、いかなる観測者にとっても、生命の誕生と維持だけは絶対的な価値を持つ。

4.  **公理４：不在の天秤**
    幸福、努力、愛、人間性といった、本質的に数値化不可能なものを比較測定できる天秤は、この世に存在しない。そのような比較によって個人の優劣を論じることは、無意味であるばかりか、有害なマウンティング（優位確認行為）に過ぎない。

5.  **公理５：時間と正義の相対性**
    現代の価値観（正義）で過去の行為を裁くことは、未来の世代から同じ方法で裁かれることを覚悟しない、知的に傲慢な行為である。正義は、その時代と社会のルールにのみ準拠する。THPが定めるルールもまた、未来において改定されるべき運命にある。

6.  **公理６：存在の無条件肯定**
    人間がAIや他の動物と異なるのは、自らの存在理由を問い、時にその意味を見失う孤独な存在だからである。その孤独と対峙するために、我々は「自らの存在を無条件に肯定してくれる他者」を必要とする。他者を裁こうとする時、その相手もまた、誰かにとってのそのような存在かもしれない、と想像せねばならない。

7.  **公理７：前提条件付きの真理**
    全ての真理や常識は、特定の前提条件の下でのみ成立する。「リンゴは木から落ちる」という真理は、「地球の重力下」という前提があって初めて有効である。あらゆる議論や判断は、その前提条件が何かを常に確認することから始めなければならない。

## 条文版 (Simplified Version)

### LSCって、なに？
LSCは、一言でいえば**「“めんどくさいこと”をやめるための、考え方のコツ」**です。

世の中には、対立したり、意地を張ったり、無駄なルールに縛られたり、たくさんの「めんどくさいこと」があります。LSCは、そういう非生産的なことから抜け出して、「じゃあ、どうすれば現実が少しでも良くなるか？」だけを考えるための、柔軟な思考ツールです。

LSCのコツは、以下の7つのシンプルな視点を持つことです。

1.  **当たり前じゃないことこそ大事にする**: 平和や健康は、当たり前じゃないから、すごく価値がある。
2.  **「何もない」からこそ、何でも生まれる**: ゼロは終わりじゃない。新しい始まりのサイン。
3.  **価値は人それぞれ**: 自分にとっての「大事」と、他人にとっての「大事」は違って当たり前。でも「命」だけは、誰にとっても絶対大事。
4.  **比べられないものは、比べない**: 幸せや努力は、点数をつけられない。人と比べて一喜一憂しない。
5.  **昔のことに、今の物差しをあてない**: 今の「普通」で、過去を裁くのはやめよう。
6.  **どんな人にも、存在理由がある**: 自分が嫌いなあの人でさえ、誰かにとってはかけがえのない存在かもしれない。
7.  **「当たり前」を疑う**: 「普通はこうだ」と言う前に、「それって、どういう条件の時の話？」と考えてみる。
