# 暗号署名モジュール設計案

## 背景と目的

AI‑TCP/KAIRO プロジェクトにおいて、メッセージの完全性と発信元の真正性を保証するために暗号署名が欠かせません。既存の `/send` `/receive` ではプレーンな署名形式が用意されていますが、暗号学的に安全な署名検証を実装する段階へ移行する必要があります。

## 選定するアルゴリズム

Ed25519 は高効率で安全性の高い楕円曲線署名アルゴリズムであり、多くのプロトコルで採用されています。Rust では `ed25519-dalek` クレートが広く使われており、秘密鍵・公開鍵の生成、署名・検証 API を簡潔に提供しています。検索結果でも、`ed25519-dalek` が「Ed25519 鍵生成、署名、検証を高速かつ効率的に提供する」[github.com](https://github.com/dalek-cryptography/ed25519-dalek#:~:text=dalek,add%20the%20following)と紹介されており、実装例の説明サイトでも「Rust と Ed25519-Dalek ライブラリを用いて署名を行う」[asecuritysite.com](https://asecuritysite.com/rust/rust_ed25519_dalek?m=abcdbcdecdefdefgefghfghighijhijkijkljklmklmnlmnomnopnopq#:~:text=Ed25519%20Signatures%20in%20Rust%20with,public%20key%20can%20prove%20it)ことが推奨されています。

## モジュール構成

コピーする編集する

`crypto/   ├── mod.rs        # エクスポートと共通型定義   └── ed25519.rs    # Ed25519 署名ロジック`

### mod.rs

rust

コピーする編集する

`// crypto/mod.rs pub mod ed25519;  /// 署名を表す共通型 pub struct Signature(pub [u8; 64]);`

### ed25519.rs

rust

コピーする編集する

`use ed25519_dalek::{Keypair, Signature as DalekSignature, Signer, Verifier, PublicKey, SecretKey}; use rand_core::OsRng; use super::Signature;  /// 鍵ペアを生成する pub fn generate_keypair() -> (PublicKey, SecretKey) {     let mut csprng = OsRng;     let keypair: Keypair = Keypair::generate(&mut csprng);     (keypair.public, keypair.secret) }  /// メッセージに署名する pub fn sign_message(secret: &SecretKey, message: &[u8]) -> Signature {     let public = PublicKey::from(secret);     let keypair = Keypair { secret: secret.clone(), public };     let sig: DalekSignature = keypair.sign(message);     Signature(sig.to_bytes()) }  /// 署名を検証する pub fn verify_signature(public: &PublicKey, message: &[u8], signature: &Signature) -> bool {     let dalek_sig = DalekSignature::from_bytes(&signature.0).expect("invalid signature bytes");     public.verify(message, &dalek_sig).is_ok() }`

## 使い方例

rust

コピーする編集する

`use crypto::ed25519::{generate_keypair, sign_message, verify_signature};  fn main() {     let (pk, sk) = generate_keypair();     let message = b"hello world";     let signature = sign_message(&sk, message);     assert!(verify_signature(&pk, message, &signature)); }`
