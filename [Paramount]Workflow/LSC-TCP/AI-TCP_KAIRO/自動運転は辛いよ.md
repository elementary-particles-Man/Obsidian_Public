## ✅ 【AutoMate JSON出力ルール】

1. **1入力に対して、必ずJSONは1件のみ出力**
    
    - 追加の補完、候補生成は禁止
        
    - 途中で複数候補が連続生成される場合は即バグ扱い
        
2. **生成するJSONの構造**
    
    json
    
    コピーする編集する
    
    `{   "task": "write_file",   "target_path": "./logs/work_results.txt",   "content": "(内容)" }`
    
    - `content` は指定がない限りランダム文字列で生成
        
    - `[AutoMate]` の入力に応じて動的に中身を決める
        
3. **連続処理は必ず「1入力→1生成」を繰り返す**
    
    - 一括複数生成やバッチ生成はしない
        
    - CLI/スクリプト側で必要ならループで受ける
        
4. **内部補完の多重生成が起こった場合**
    
    - 即座にバグ扱いでログに残す
        
    - ユーザーに同じ内容が繰り返し返らないようにする

## 🛠 【この問題の開発チームへの報告内容（案）】

### 📝 バグ概要

> GPT-4o において「単一の構造化JSONを返すだけのシンプルなタスク」においても、  
> 内部の補完候補が多重生成されることで、  
> 1入力に対して10件以上の同一JSONが連続出力される挙動が観測されました。

### 🚩 問題点

- ChatGPTの「連続補完アルゴリズム」が、  
    同じ生成を繰り返す場合の止めどころを持たない
    
- 設定で明示的に「補完候補数＝1」とできない
    
- ログとして残るため、CLI連携や自動化で致命的な二重処理が発生する
    

### 📌 必要な改善要望

- **Chatモードでも「出力件数上限（N=1固定）」を設定可能にする機能**
    
- 構造化出力の場合、必ず一回の応答で補完を完結させるスイッチ
    
- 生成API側で多重補完を抑止するフラグ提供
