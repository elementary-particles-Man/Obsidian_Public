# プレアヴィヒアの配当：2008年-2011年タイ・カンボジア紛争における経済的受益者と資金フローに関するインテリジェンス評価

## 第1部：エグゼクティブ・サマリー

**最重要評価：** 本報告書は、2008年から2011年にかけてのタイ・カンボジア国境紛争を理解する上で、「構造汚職仮説」が有効な枠組みであると高い確度で結論付ける。この紛争は真の国家主義的対立に根差しているものの、その期間、激しさ、そして「非合理的」なレベルの軍事支出は、タイの軍部、政治エリート、および関連する商業事業体内の関係者ネットワークに利益をもたらす強力な経済的インセンティブによって動かされていた。

**主要な受益者：** 主な受益者は以下の通りである。(1) タイ王国軍内の派閥、特に第二軍管区。彼らは膨張した作戦予算へのアクセスと、非合法な国境経済の支配権を得た。(2) 不透明で非競争的な調達契約から利益を得た国内外の防衛関連請負業者およびその現地代理人のネットワーク。(3) 紛争を利用して軍事支出の増額を正当化し、権力を固めた保守的な政治勢力。

**利得のメカニズム：** 利益は主に3つの経路を通じて生み出された。(1) 公式および予算外の国防資金の流用および不正支出。(2) 国家安全保障上の例外規定によって可能となった軍需物資およびサービスの調達契約におけるキックバックと価格の吊り上げ。(3) 麻薬や武器を含む非合法な越境貿易の管理と課税、および押収された禁制品の不正流用の可能性。

**戦略的含意：** この紛争は、これらの既得権益ネットワークにとって成功した「ビジネスモデル」として機能し、作り出された、あるいはエスカレートした安全保障上の危機が非常に収益性の高いものになり得ることを示した。このモデルは、地域の安定に対する潜在的な脅威であり続け、タイにおける真の安全保障分野の改革に対する重大な障害となっている。

## 第2部：プレアヴィヒアの発火点：政治的混乱と紛争の口実

このセクションでは、2006年のクーデター後のタイの政治環境が、収益性の高い軍事行動にとって理想的な口実を提供したことを立証する。国家主義的な熱狂は究極的な原因ではなく、必要不可欠な触媒であった。

### 潜在的紛争の政治問題化

1世紀にわたる国境紛争は 、2008年に新たな領土侵犯によってではなく、カンボジアがプレアヴィヒア寺院をユネスコ世界遺産として登録することに成功したことで再燃した 。  

### 分断されたタイにおける国家主義の武器化

2006年にタクシン・シナワットを追放した軍事クーデターの後、タイの政治は反タクシン派の「黄シャツ隊」（保守的な既成勢力と軍が支持）と親タクシン派の「赤シャツ隊」との間で激しく二極化した 。黄シャツ隊は、ユネスコの登録を利用して、当時のサマック・スンタラウェート首相率いる親タクシン政権を攻撃し、タイの主権を売り渡す裏切り行為であると非難した 。これにより、強硬な軍事的対応を求める巨大な国内圧力が生まれた。  

この政治的危機は、紛争の「市場開拓者」として機能した。それは、軍事的な解決策に対する国民的・政治的な需要を創出し、それが今度は本調査の核心である財政的な機会を解き放った。紛争は政治の不幸な結果ではなく、その支持者にとって予測可能で望ましい経済的結果を伴う意図的な政治戦略であった。紛争を国家主権の防衛と位置づけることで、その後に続く行動、すなわち防衛費の大幅な増額に対して、政治的に反論の余地のない正当性が与えられた。2006年のクーデターによってすでに強化されていた軍の制度的権力は、自らを外部の脅威に対する唯一の国家防衛者と位置づけることでさらに強固になり、その予算や影響力に対する批判者を沈黙させた 。  

### アピシット政権と軍の台頭

紛争は、軍に支持され、親タクシン政党の解党後に政権を握ったアピシット・ウェーチャチーワ首相（2008年-2011年）の下でエスカレートした 。この政権は軍とその保守的な同盟勢力に対して政治的な借りがあり、軍からの資源や作戦上の裁量権に対する要求を非常に受け入れやすい状況にあった。軍は、カンボジアを主要な外部の脅威と位置づけた 。  

## 第3部：国防予算配分と資金フローの分析

このセクションでは、紛争期間中に異常かつ不透明な資金の急増が軍に向けられたことを示し、報告書の定量的な裏付けを提供する。

### クーデター後の予算爆発

分析によると、平時の通常の傾向から逸脱し、クーデター後の政治的連携と国境紛争と完全に一致する、劇的かつ持続的な国防費の増加が示されている。

- 2006年のクーデター以前、年間予算の増加率は約3-5%と穏やかであった 。  
    
- クーデターによって設置された政権下の2007会計年度において、国防予算は**33.8%**増の1,150億バーツに急増した 。  
    
- 紛争が始まった2008会計年度には、さらに**24.7%**増の1,430億バーツに達した 。  
    
- この傾向はアピシット政権下でも続き、2009年には**18.5%**の増加が見られた 。  
    
- SIPRI（ストックホルム国際平和研究所）のデータも、この傾向を恒常米ドルで裏付けており、2007年の50.7億ドルから2008年には53.18億ドルへと着実に増加し、2009年には53.06億ドルでピークに達した後、わずかに減少している 。GDPに占める割合も、2000年代半ばと比較してこの期間中は高い水準で推移した 。

### 不透明性の構造

公式予算は物語の一部しか語らない。タイの国防財政システムは、資金の流用を可能にするための不透明性を意図して設計されている。

- **予算外の「裏金」:** 国防省は、財政規律法から免除されている、推定約180億バーツ（総予算の約8%）に上る予算外の支出メカニズム、すなわち「裏金」を利用している 。  
    
- **脆弱な監督機能:** 議会の監督機能は構造的に脆弱である。議会は予算全体を承認または否決できるが、その小委員会が個別の項目を精査したり、調達を中止させたり、さらなる調査を要求したりする権限は限定的である 。軍の内部監査プロセスは独立性と透明性を欠き、報告書はしばしば単なる要約に過ぎない 。  
    
- **分散化された管理:** 予算権限は分散化されている。議会がトップラインの予算を承認すると、資金は各軍（陸・海・空）の司令官に直接分配され、司令官は資金の使途について大きな裁量権を持つ 。この構造は、説明責任が拡散されるため、縁故主義や汚職の温床となる。  
    

これらの事実から、紛争中の国防予算が単なる戦争遂行のための道具ではなかったことが示唆される。軍の「パラレル・ステート（並行国家）」としての地位は、政治に対する絶大な影響力を与えている 。大規模で不透明な予算の増加は 、国防以上の目的に使用可能な資金プールを意味する。軍の派閥と政党が深く絡み合ったシステムにおいて 、これらの資金は忠誠者への報酬、潜在的なライバルの懐柔、そして政治活動の資金源として、「国家安全保障」という名目の下で利用され得る。したがって、この紛争は軍を組織として豊かにしただけでなく、激しい国内対立の時期に権力を維持するための、監査不能な巨大な軍資金を、政権を握る政治・軍事連合に提供した。国防予算は、外部の敵（カンボジア）と国内の敵（親タクシン派野党）の両方と戦うための重要な手段だったのである。  

## 第4部：戦争の受益者：調達、縁故主義、そして利益

このセクションでは、軍の調達システムを通じて紛争から直接利益を得た企業や個人の関係者を特定する。

### 調達の「ブラックボックス」：汚職のために設計されたシステム

- **国家安全保障の例外規定:** 公共調達・供給管理法（2017年およびそれ以前の規則）は、国家安全保障に関連する調達を、標準的な透明性や競争要件から明確に除外している 。この法的抜け穴が、国防セクターにおける汚職の礎となっている。  
    
- **仲介者の役割:** このシステムは、官僚機構を渡り歩き、契約を確保するために不可欠な現地代理人や代表者の利用を奨励している。これにより、キックバックや手数料が支払われる可能性のある追加の層が生まれる 。実業家たちは、政府機関から契約を獲得するために、平均25%を超える「裏金」が標準的であると認めている 。  
    
- **説明責任の欠如:** このシステムは透明性の欠如を特徴とし、調達や資産処分に関する詳細はしばしば公記録から省略される 。偽のGT200爆弾探知機や戦略的に疑問の残る中国製潜水艦の購入といった悪名高い事件は、説明責任が事実上存在しないシステムを浮き彫りにしている 。  
    

### 請負業者のネットワーク

紛争は、ハイエンドな装備品と日常的な消耗品の両方に対する需要を急増させ、さまざまな企業に利益をもたらした。

- **国内企業:** **チャイセリ・ディフェンス（Chaiseri Defence）**のような企業（装甲車両および車両部品の製造業者）は、南部での反乱や国境警備を念頭に置いて2009年に自社の「ファースト・ウィン」4x4車両を開発するなど、この時期に活発に活動していた 。2008年から2011年の具体的な契約は詳述されていないが、車両の修理、アップグレード、部品生産におけるタイ王国軍との確立された関係から、作戦テンポの向上や車両のメンテナンス・交換の必要性から利益を得た可能性が高い受益者として位置づけられる 。  
    
- **国際的供給業者:** **タレス（Thales）**のような主要な国際企業は、タイ軍への供給において50年の歴史を持ち、海軍向けのシステムや、陸軍向けの電子戦、通信、レーダーシステムを提供している 。紛争は、メンテナンス、スペアパーツ、そして潜在的には新しいシステムへの需要を増加させたであろう。米国、中国、ヨーロッパからの他の供給業者も重要なパートナーである 。  
    
- **日常的な供給業者:** 最も重要で追跡が最も困難な利益は、燃料、弾薬、食料、輸送サービスの供給業者にもたらされた可能性が高い。これらの大量かつ継続的な契約は、過剰請求やキックバックの主要な手段であり、地域の軍司令官や政治家と密接な関係を持つ企業に利益をもたらす。

## 第5部：影の経済：非合法貿易と押収資産の管理

このセクションでは、紛争地帯を支配することによって生み出される、帳簿外の直接的な収益源を探る。

### 紛争と密輸ルートの支配

- タイ・カンボジア国境は、麻薬（メタンフェタミン）や非合法武器の密輸を含む、国境を越える犯罪の確立された回廊である 。  
    
- 紛争中の国境の軍事化は、**タイ王国軍第二軍管区**にこれらの密輸ルートの直接的な物理的支配権を与えた 。  
    
- この支配は強力な経済的機会を生み出す。展開された軍の派閥はゲートキーパーとして機能し、ライバルと連携する密輸ネットワークを遮断する一方で、好意的なネットワークには課税したり安全な通行を提供したりすることができる。紛争自体が、その地域における非合法経済を独占するための道具となる。報告書は、「国家に組み込まれた関係者」、特にタイとカンボジア両国の軍当局者が、地域の武器密輸ネットワークの要であると明確に言及している 。

### 押収品の行方：闇市場への潜在的な横流し

- 国境沿いの治安作戦では、特に麻薬などの禁制品が大量に押収されることが頻繁にある 。  
    
- 押収品の公式な処理プロセスは複雑である。一部は破壊されることが定められているが 、その他は国家に帰属させることができ、資金は財務省などの機関に分配される規定がある 。  
    
- 重大な脆弱性は、管理の連鎖（chain of custody）に存在する。押収から破壊または処分までの過程における透明で独立した監督の欠如は、漏洩の重大なリスクを生み出す。高価な麻薬は、実際の量のほんの一部として記録され、残りはそれを押収した当局者自身によって横流しされ、闇市場に再導入される可能性がある。これは、腐敗した要素にとって直接的で追跡不可能な現金源となる。軍が不透明な商取引や内部の汚職スキャンダルの歴史を持つという事実は、この可能性の信憑性を高めている 。

「構造汚職仮説」は**可能性が非常に高い**と評価される。タイの既得権益層内の主要な派閥が紛争を開始し、維持し、エスカレートさせる経済的インセンティブは、強力かつ体系的であった。タイの国際的地位を損なった戦争の「非合理的」なコストは 、大規模な国家公認の利権獲得スキームとして見なした場合、完全に合理的となる。

## 第7部：戦略的含意と提言

このセクションでは、クライアント向けの将来を見据えた分析を提供する。

### 永続する脅威

根本的な構造、すなわち軍の「パラレル・ステート」としての地位、その経済的権益 、不透明な調達システム、そして政治的影響力 は、根本的に改革されていない。したがって、「利益のための紛争」モデルは、これらのネットワークにとって依然として実行可能で魅力的な選択肢であり続けている。  

### 将来の発火点

将来のいかなる国境の緊張、国内の政治危機、あるいは大規模な自然災害でさえも、同様の予算増額と不透明な支出のサイクルを引き起こす口実として利用され、この腐敗したエコシステムを再活性化させる可能性がある。

### さらなる情報収集のための提言

- 2008年から2011年の期間における第二軍管区の退役および現役の上級将校のビジネス上の利益と企業役員の経歴に焦点を当てる。
    
- 紛争中に東北部の各県で契約を獲得した小規模な物流、燃料、サービス企業の企業記録を追跡する。
    
- 潜在的な漏洩を特定するために、押収された麻薬の公式報告と地域の闇市場情報との間の不一致を監視する。
    

### クライアントへの政策提言

- 広範な国家安全保障の例外規定を排除するために、公共調達法を改革するようタイに国際的な圧力をかけることを提唱する。
    
- 軍・政・産の複合体における主要な結節点として特定された個人および企業体に対する標的型金融制裁を検討する。
    
- 軍の汚職を暴露するために活動しているタイの市民社会組織や調査報道機関（例：Prachatai、Isranews）を支援する 。
