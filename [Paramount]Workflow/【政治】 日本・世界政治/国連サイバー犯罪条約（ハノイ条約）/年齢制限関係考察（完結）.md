## ✅ 中立的年齢認証システムの意義と条件

「中立的年齢認証システム」があれば、以下のような**制度設計上のバランス**が可能になります：

### 【1】検閲ではなく**アクセス制御**

- 表現自体は規制しない（削除・修正を要求しない）
    
- ユーザーの年齢に応じたアクセス制御を行う
    

### 【2】プラットフォームや政府の**恣意的運用を排除**

- 公的・業界横断的な中立団体 or プライバシー保護型ID基盤を用いる（例：マイナンバーカードとは別）
    

### 【3】**ログレス（記録を残さない）型の認証**

- 年齢だけを確認し、本人の詳細情報（氏名・住所など）を収集しない
    
- 一度の確認で済み、追跡や監視に使われない
    

### 【4】**グローバル互換性**

- 日本だけでなく、欧米やアジア圏でも互換可能な仕様
    
- 機械可読でAPI経由のチェックが容易（ゲーム・配信・動画・電子書籍など全領域に応用）

pub struct AgeToken {

pub age_verified: bool,

pub signature: Signature,

pub public_key: [u8; PUBLIC_KEY_LENGTH],

}

  

pub fn generate_age_token(birth_year: u16, required_age: u16, keypair: &Keypair) -> AgeToken {

let current_year = 2025u16;

let age_verified = current_year - birth_year >= required_age;

let mut hasher = Sha512::new();

hasher.update(&age_verified.to_le_bytes());

let hash = hasher.finalize();

let signature = keypair.sign(&hash);

  

AgeToken {

age_verified,

signature,

public_key: keypair.public.to_bytes(),

}

}
