# 導入提言書：緊急人道支援における次世代決済監査システム「THP-CLEAR」の導入について

文書ID: THP-CLEAR-PROP-HUMANITARIAN-v1.0

作成日: 2025年11月7日

ステータス: 提案

作成者: The Horizon Protocol 編纂者

## 1. 提言の趣旨と目的

### 1.1. 背景

近年の国際情勢の不安定化に伴い、紛争地域や大規模災害被災地への緊急人道支援活動において、支援金の迅速かつ透明性の高い送金が喫緊の課題となっています。従来の金融網は、インフラの破壊や政情不安により機能不全に陥るケースが多く、支援が末端まで届かない事態が頻発しています。

### 1.2. 目的

本提言は、日本円に価値が裏付けられたステーブルコイン（JPYC等）を活用し、低コストかつ強靭な決済監査システム「THP-CLEAR」を導入することで、人道支援活動における決済の継続性と透明性を確保することを目的とします。

本システムは、**平時・有事の双方で運用可能な軽量分散アーキテクチャ**として機能し、有事においても支援金の流れを正確に追跡可能にします。

## 2. システムの概要：中立的監査レイヤ

THP-CLEARは、**資金の保管・送金・為替取引を一切行わず、二者間の決済事実のみを不可逆的に記録する中立的監査レイヤ**です。

そのため、資金決済法等の規制における「為替取引」には該当せず、シンプルな三層構造で迅速な導入が可能です。

|**層**|**役割**|**主な機能**|
|---|---|---|
|**MQ (受付層)**|決済リクエストの受付と整列|・管理機関と決済機関からの情報をペア化<br><br>  <br><br>・取引IDと時刻を付与|
|**WN (検証層)**|取引内容の突合と検証|・二系統の情報の整合性を確認<br><br>  <br><br>・電子署名により取引を確定|
|**DB (保存層)**|検証済み記録の永続保存|・監査証跡（Witnessログ）を記録<br><br>  <br><br>・データの分散冗長化と自己修復|

電源は民生品のUPSを想定しており、停電時にも一定時間の稼働が可能です。

## 3. 技術仕様ハイライト

### 3.1. 通信データ形式：完全固定長パケット

全トランザクションは、**AES-256-GCM外装で封緘した352バイト（2,816ビット）の完全固定長パケット**で処理されます。これにより、通信効率を最大化し、システムの処理負荷を極限まで低減します。

### 3.2. 監査証跡（Witnessログ）と冪等性

検証が完了した取引は、**固定長128バイト**のレコードとして記録されます。全ての取引記録は、冪等キー`H`（`H = SHA3-256(TxID ‖ Timestamp_ISE)`）を主キー（SSOT）として記録されるため、通信障害時にも二重記帳の心配がありません。

### 3.3. 暗号資産等の取り扱い（VoidCoin）

本システムは、金銭価値の移転を伴わない物資支援の記録やシステムテストのため、「VoidCoin」という概念を導入します。これは**価値ゼロの「存在証明トークン」**であり、投機的利用の余地はありません。

厳格な条件下（`ExchangeFlag=1`、交換所ノードの関与、VoidCoin同士の交換禁止）でのみ、ステーブルコインとの交換証跡を記録します。

## 4. 物理システム構成とコスト

汎用の省電力ミニPCを活用し、**約2,000万円（100ノード構成、税抜）**という低コストで導入が可能です。これは従来の金融システム構築・維持費用と比較して数桁低い水準であり、人道支援領域において極めて高い費用対効果を発揮します。

## 5. 運用設計とリスク評価

### 5.1. 責任分界

システムの安定運用のため、システムそのものの管理責任（THP-CLEARチーム）と、通信インフラの管理責任（現地協力団体/自治体等）を明確に分離します。

### 5.2. 自己修復メカニズム

一部の機器が物理的に破壊・損失されることを前提として設計されており、データの分散・暗号化コピーと、新ノード起動時の自動復元（再実体化）機能を備えています。これにより、**人為的な操作をほぼ介さずにシステムの完全性が維持**されます。

### 5.3. リスク評価

本システムは「シンプルさと堅牢性」により、多くのリスクは構造的に低減されています。

- **技術的リスク対策**: 機器の冗長化、低帯域設計、クラウド非依存（複数クラウド＋自治体NWへの分散）により、単一障害点を排除します。
    
- **運用上のリスク対策**: 自律運用（電源投入で自動機能）、データの暗号化、個人情報非保持（PIIを保持しない）設計により、現地負担と情報漏洩リスクを最小化します。
    
- **法的リスク対策**: THP-CLEARは資金移動を行わない「中立的監査レイヤ」であるため、資金決済法等の「為替取引」には該当しません。
    

## 6. 導入計画（ロードマップ）

リスクを管理しつつ着実な導入を図るため、3段階のロードマップを提案します。

- **フェーズ1：国内実証実験 (T+0～3ヶ月)**
    
    - 目的: システムの基本機能と安全性を国内環境で最終検証する。
        
    - KPI (例): p99 ACK遅延 < 300秒
        
- **フェーズ2：パイロット導入 (T+3～6ヶ月)**
    
    - 目的: 実際の支援活動に試験導入し、実環境での有効性を評価する。
        
    - KPI (例): データ復旧時間 10GBあたり < 25分、日次監査不整合 0件
        
- **フェーズ3：本格運用と拡大 (T+6ヶ月以降)**
    
    - 目的: システムを本格稼働させ、他の人道支援活動への適用を拡大する。
        

## 7. 結論

THP-CLEARは、最先端の技術を応用しつつも、「人道支援のための、低コストで運用が容易な決済監査システム」として設計されています。本システムの導入により、我が国が国際的な人道支援活動において主導的な役割を果たし、支援の透明性を世界に示す一助となることを確信しております。
