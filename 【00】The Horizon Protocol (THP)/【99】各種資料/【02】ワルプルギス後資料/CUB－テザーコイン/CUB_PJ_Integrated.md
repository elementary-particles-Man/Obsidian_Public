# CUB/USDT 統合報告（THP-PJ-standard）

## Executive Summary
- CUBは唐代の「飛銭」起源の相殺型信用ネットワークにUSDT（TRON/TRC-20）を重ねた影の決済レール。ミラー・スワップで資金は国境を越えず、USDT送金でブローカー間債務を即時清算する。
- 需要源（中国の5万ドル規制超過によるRMB売り）と供給源（麻薬カルテル・北朝鮮・ロシアの汚染USD/クリプト）が手数料0〜2%で結合し、従来の高コスト洗浄網を置換した。
- TRON/USDTは低手数料・即時性・凍結耐性期待によりCUB決済を独占。スマートコントラクト凍結権限（addBlackList）が存在し、OFAC/DOJの制裁対象候補という脆弱性を内包する。
- 地域ハブは日本（統合/資産貯蔵）、北米（現金源）、東南アジア（詐欺生成）、ロシア（国家決済代替）。欧州はエネルギー・産業後退とロシア制裁迂回の両圧力に晒される。
- USDT担保は米国短期国債を中心に約1,000億ドル規模（テザー社主張）で、ドル債市場とシャドー決済圏を連結。凍結シナリオは日本不動産・暗号市場・ロシア兵站に同時ショックを与える。
- THP階層では、CUB/USDTはTHP-0の世界再定義層で発生した「影のレール」として位置付けられ、THP-1/2での透明化・統制、THP-Economyでの円本位/CLEARによる遮断が必要。

## 1. 目的（Scope）
- CUB/USDT構造をPJ-standardで統合し、因果のみで整理する。
- TRON/USDT技術構造・脆弱性、ロシア・中国金融接続、欧州・米地方金融への波及経路を一次情報に基づき明示する。
- THP各レイヤとの接続位置を定義する。

## 2. 定義（Definitions）
- CUB: Chinese Underground Bank。鏡像取引による相殺決済網。
- ミラー・スワップ: 国内RMB入金と海外USD/USDT支払いを並行実行し、帳簿上で相殺する手法。
- USDT(TRC-20): TRON上のテザー。低手数料（数セント）、高速ファイナリティ。
- Tier構造: Tier1（CCP/国企/超富裕層）、Tier2（カルテル・北朝鮮・ロシア組織犯罪）、Tier3（富裕中間層/SME）、Tier4（留学生・代購・観光客）。
- 影のSWIFT: CUB/USDTが提供する非公式決済レール。

## 3. 事実関係（Facts）
- 規制背景: 中国外貨枠5万ドル/人/年。これを超える資本逃避需要が持続。
- 手数料: CUBはカルテル等に対し0〜2%（場合によりマイナス）でUSDを買い取ると記載。
- USDT担保: テザー社は米国短期国債約1,000億ドル規模を保有と説明。USAT新設でリスク分離を模索。
- TRON選好理由: 手数料数セント、即時決済、ERC-20/USDCより凍結リスクが低いとの認識（近年変化しつつある）。
- 米制裁動向: DOJが銀行詐欺/テロ資金看過容疑を捜査。OFACはスマートコントラクト制裁（核オプション）を検討と記載。
- ロシア接続: Garantexが1,000億ドル超の取引（Elliptic調査）。モスクワ-深圳ミラースワップで軍需調達を実施。SWIFT排除後の人民元決済遅延をCUB/USDTで解消。
- 日本統合ハブ: 池袋・湾岸・大阪で現金一括/1+1取引を通じ資金統合。ANAP型資金還流事例が指摘。
- 欧州状況: ドイツの脱工業化（エネルギー高騰・工場閉鎖）とロシア制裁回避需要が並存。CUB/USDTはロシア-中国間物流の迂回決済に利用。
- 米地方金融: CRE・muni bondsとの直接接続について一次情報は未提示。本報告では未記載。
- イスラエル/中東資金流: 本セットに統計一次情報なし。記載を留保。
- NYC犯罪統計: 本セットに一次情報なし。記載を留保。

## 4. 構造分析（Structural Analysis）
- 需給結合: RMB逃避需要（Tier1/3）と汚染USD供給（Tier2）がCUBでネッティング。TRON/USDTが清算レイヤ。
- 技術層: TRONは低Fee・高速ブロックでスマーフィング向き。USDTコントラクトは中央化された凍結権限を持ち、制裁リスクと可用性の両面を内包。
- 地域ノード: 日本=Integration、北米=Placement、東南アジア=生成（詐欺・オンラインカジノ）、ロシア=国家決済代替。欧州はロシア向け迂回需要と産業後退が交差。
- 流通量と担保: USDTは米国債保有でドル債市場と直結。凍結は流動性を瞬時に削減。
- 政策・規制: GENIUS法等でUSDC優遇/USDT排除の議論。Tether側はUSATで準拠・非準拠を分離し存続を図る。

## 5. 因果連鎖（Causal Chains）
- 資本規制（5万ドル枠）→ RMB逃避需要増 → CUB ingress拡大 → TRON/USDT決済採用 → 手数料低下 → カルテル/北朝鮮/ロシアがUSD供給をCUBにシフト → Tier1/3資金とネッティング → 日本不動産・海外学費等へ統合。
- SWIFT制裁/人民元決済遅延（ロシア） → Garantex経由USDT調達 → モスクワ-深圳ミラースワップ → 軍需部品調達継続 → OFAC/DOJ制裁圧力上昇 → TRON/USDT凍結リスク増大。
- TRON/USDT凍結（OFAC核オプション想定）→ 日本のUSDT滞留資金凍結・不動産買い圧力消滅 → ロシア兵站決済停止・ルーブル暴落 → CUB流動性枯渇 → Tier2/3/4ネットワーク崩壊。
- ドイツ/フランスのエネルギー高騰・産業後退 → ロシア代替調達コスト上昇 → 非公式決済への誘因増 → CUB/USDT迂回利用拡大。

## 6. リスク分類（Risk Taxonomy）
- 技術リスク: USDTスマコン凍結権限・TRONノード制裁による停止。
- 流動性リスク: USDT担保凍結・償還停止による瞬時デフレ（暗号・不動産・ロシア兵站）。
- 規制リスク: GENIUS法等による銀行アクセス遮断、SDN指定によるOTC閉塞。
- 地政学リスク: ロシア・北朝鮮・カルテルへの依存が制裁標的を集中化。
- 伝播リスク: 日本不動産/暗号保有者、欧州産業の資金繰り、ロシア調達の同時収縮。
- 未観測リスク: 米地方金融（CRE/muni）、イスラエル/中東資金流、NYC犯罪統計については一次情報欠如のため評価保留。

## 7. THP体系との接続（Integration Layer）
- THP-0（世界再定義）: TCW崩壊後のRWMで生じた影の決済レールとしてCUB/USDTを位置付け。
- THP-1（民族憲章）: 資本移動の透明化要件を憲章に組込み、CUB型無記名流通を非準拠領域として定義。
- THP-2（倫理憲章 + 断罪/贖罪）: 価値判断ではなく、出所証明義務と証跡ログ未整備資金の排除を制度化。
- THP-UNrev2（国連再編）: スマコン制裁やOTCクラスター指定を国際協調枠組みに載せ、影のSWIFTを多国間で遮断。
- THP-Economy（Fiat-U / 円保障経済制度）: SRFで対中債権を買い上げCUB需要を遮断し、CLEAR/JPYCによる証跡付円本位経済でホワイトゾーンを形成。

## 8. 結語（Closing Notes）
- 本稿は提供ドキュメントの一次情報に基づき、因果と構造のみに絞って整理した。未観測領域（米地方金融、イスラエル/中東統計、NYC犯罪統計）は追加データ到着後に補完する。 TRON/USDT制裁動向と日本国内USDT滞留量のモニタリングが即時優先。 SRF/CLEAR/JPYC実装により、CUB依存の需要側を縮減し、影のレール遮断をTHP体系に組み込む。
