# Authority Model for CLEAR Nodes (Safe Edition)

## Node Types
- **National Node:** operated by sovereign institutions
- **Regional Node:** redundancy only
- **Audit Node:** verifies timestamp integrity

## Forbidden Capabilities
- Tracking
- Inference
- Behavioral modeling
- Social scoring

## Allowed Capabilities
- Hash consistency validation
- Timestamp reconciliation
- Key lifecycle attestation

## Neutrality
CLEAR must not:
- Rank individuals
- Evaluate compliance
- Enforce policy
