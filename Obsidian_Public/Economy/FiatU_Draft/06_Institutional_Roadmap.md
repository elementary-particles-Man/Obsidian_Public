# Fiat-U Institutional Implementation Roadmap (Draft)
> **Note:** This document is a *draft* and not a final institutional design.

## 1. Purpose
To outline a practical, staged implementation path for Fiat-U, aligned with GSSH mitigation and international financial transparency.

## 2. Principles
- Minimal disruption to existing fiat systems
- Full backward compatibility with current accounting/CB-Treasury operations
- Transparency-first, enforcement-second
- Implementation via opt-in layers

## 3. Roadmap Phases
### Phase 0 — Transparency Baseline (0–6 months)
- Mandatory publication of T-value components (audit, fiscal space, CB sync)
- CLEAR-based audit logs enabled for pilot institutions

### Phase 1 — Fiat-U Computation Layer (6–18 months)
- National statistical offices compute provisional T-values
- IMF/OECD/BIS given observer access (read-only)
- Cross-country comparability established

### Phase 2 — Sovereign Compatibility Layer (18–30 months)
- Government bonds tagged with T-value metadata
- Market participants shift to transparency-adjusted pricing

### Phase 3 — International Integration (30–48 months)
- Coordinated T-value publication cycle
- Eligibility criteria for UBI-T channels

### Phase 4 — Full Fiat-U Operationalization (48+ months)
- Optional: Transition to Fiat-U ledger for sovereign operations
- CLEAR-based cross-border reconciliation

## 4. Governance Structure
- Lead: Ministry of Finance (Japan)
- Partners: IMF, BIS, OECD
- Implementation body: CLEAR operational consortium

## 5. Outputs
- Reduced sovereign opacity
- Stabilized global liquidity cycles
- Mitigation of GSSH stagnation vectors
