# MMT vs Fiat-U Comparison Table

| Category | MMT | Fiat-U |
|----------|-----|---------|
| Role of Tax | Maintains nominal value | Value maintenance + transparency enforcement |
| Constraint | Only inflation | T-value structural constraint |
| Bonds | Pure asset swap | Transparency-tagged sovereign instruments |
| Political Exposure | Very high | Bounded by CLEAR and metrics |
| International Applicability | Weak | Strong (IMF/BIS compatible) |
| Systemic Risk Handling | Assumes state solvency | Explicit multi-factor sovereign integrity model |

## Summary
Fiat-U retains the valid fiat insights of MMT but replaces the ambiguous components (inflation constraint, political discretion) with transparent, measurable structures.
