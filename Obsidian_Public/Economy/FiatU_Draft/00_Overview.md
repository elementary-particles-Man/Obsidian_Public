# Fiat-U Working Paper — Overview (Draft)

*This is a draft document. Not a complete system and not an institutional proposal.*

This file provides the overview of the Fiat-U framework.

## Purpose
- Provide a transparent interpretive layer for modern fiat systems.
- Fix the structural misunderstanding revealed in GSSH.
- Serve as a reversible stabilizer without creating a new currency.

## Position in GSSH
Fiat-U corresponds to the remedial layer for:
- The invisibility of fiat credit mechanics.
- The misinterpretation embedded in both fiscal and monetary doctrine.
- The lack of a shared global standard for transparency.
