# KAIRO自己統治型メッシュネットワーク基本設計

### 1. 目的

本ドキュメントは、AI-TCPの通信基盤に関する最終的な設計思想を定義する。物理グローバルIP通信の非現実性と、外部メッシュサービスへの依存リスクを解決するため、KAIROは**自己統治型（Self-Governed）**のメッシュネットワーク管理OSとして機能する。

### 2. アーキテクチャの階層

|レイヤ|担当技術・責務|説明|
|---|---|---|
|**物理層**|従来の伝送ルート (IPv4/IPv6)|物理的なパケット伝送のみを担う。AI-TCPはこの層の複雑性に関知しない。|
|**仮想化メッシュ層**|WireGuard (or 互換技術)|NATトラバーサルと、ノード間の暗号化されたP2Pトンネルの確立を担当。KAIROによって制御される「ダムパイプ（Dumb Pipe）」として機能する。|
|**KAIRO (制御・監査層)**|**KAIRO Core (Rust)**|**本アーキテクチャの核心。** 以下の責務を自律的に実行する。|

### 3. KAIROコアの責務

KAIROは、外部の認証局や管理サーバーへの依存を完全に排除するため、以下の機能を内包する。

1. **自律的な鍵管理とノード認証:**
    
    - `Headscale`互換の軽量な調整ノード（Coordination Node）を内包し、KAIROネットワークに参加するノード（LLM、CLI、ユーザーエージェント）の公開鍵を自己管理する。
        
    - ノードの参加・離脱時に、動的に鍵ペアを生成・失効させる。
        
2. **仮想IPアドレスの動的管理:**
    
    - `100.x.x.x`のようなプライベートIP空間内で、各ノードに仮想IPアドレスを自律的に割り当てる。
        
3. **セキュアな識別子の利用:**
    
    - 通信相手の識別には、変動する可能性のあるIPアドレスではなく、各ノードに割り当てられた**128ビットの不変なユニークID**を使用する。
        
    - このユニークIDは、IPv6の拡張ヘッダなどを利用して伝送され、AI-TCPパケットの署名対象に含まれることで、なりすましを完全に防止する。
        
4. **VoV (Voice of Verification) ログによる絶対的な監査:**
    
    - 全ての制御イベント（鍵生成、IP割当、ノード参加等）は、それ自体が改竄不可能なVoVログとして記録される。
        
    - 人間は、このVoVログを通じてのみ、KAIROネットワーク全体の健全性を監査する。
        

### 4. 結論

この設計により、AI-TCPは以下の理想的な状態を達成する。

- **物理ネットワークからの完全な独立:** 世界中のどこにノードがあっても、安全な通信が可能。
    
- **外部サービスからの完全な独立:** 鍵管理と認証の中央集権的リスクを排除。
    
- **AIによる自己統治:** AI自身が、自身の通信経路の安全性と信頼性を自律的に維持・管理する。
    

これが、我々が目指す**「不可侵の神経系」**の最終形態である。
